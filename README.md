# Alpine Messenger

Pet-проект, который написан для изучения микросервисной архитектуры, каналов, Go-рутин, Websocket, Docker, JSON, API (в данном случае показывает погоду)

В итоге получилось разработать работающее приоложение где пользователь регистрируется, на своей страничке он может писать посты, добавлять друг друга в друзья, и общаться с ними. 

---

## Функционал

- регистрация и авторизация (JWT)
- профиль пользователя
- создание постов
- добавление в друзья
- чат между пользователями
- получение прогноза погоды через внешний API (сам ключ в переменной окружения WEATHER_API_KEY=fs...)

---

## Как это устроено

Проект разбит на несколько сервисов + API Gateway.

Gateway:
- принимает все запросы
- проверяет JWT
- прокидывает данные пользователя дальше

Сами сервисы:
- не занимаются авторизацией
- просто берут данные из заголовков

Пример:

```go
if userID, ok := claims["user_id"].(float64); ok {
    r.Header.Set("X-User-ID", fmt.Sprintf("%.0f", userID))
}

```
##  Технологии

| Технология | Назначение |
|------------|-----------|
| **Go** | Язык реализации бэкенда |
| **MySQL** | Реляционная база данных |
| **Docker + Docker Compose** | Контейнеризация|
| **JWT** | Аутентификация и авторизация |
| **bcrypt** | Хэширование паролей |
| **REST API** | Архитектура взаимодействия |

## База данных

### Основные таблицы

```sql
users      -- Пользователи (id, username, email, password_hash, created_at)
posts      -- Посты (id, user_id, content, created_at, updated_at)
messages   -- Сообщения чата (id, sender_id, receiver_id, content, timestamp)
friends    -- Друзья и заявки (id, user_id, friend_id, status, created_at)
```
